# Foundations_of_Deep_Learning

Implementation of the Fundamental Components Pivotal to the Realization of Artificial General Intelligence (AGI) through the Utilization of Deep Learning Methodologies, including 20-Way One-Shot Classification, on Omniglot Dataset.

The primary objective of this project is to undertake the implementation of fundamental
components essential to the realization of Artificial General Intelligence (AGI) through the
employing of deep learning techniques. These foundational components can be categorized as
causality, compositionality, and learning-to-learn.

These aforementioned concepts were researched and implemented in models, particularly within the
domain of Cognitive Science research1,2,3. The main aim of such research can be briefly
summarized as the mimic of human learning, perception and cognitive processes for machine
systems : as Lake et al. (2017) put forward , building machines that see, learn and think like people.
Hence, my approach shall goes beyond mere pattern recognition, emphasizing the imperative of
comprehensive model construction.
